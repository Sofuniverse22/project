## 1. 프로젝트 개요

### 1.1 제품명
**스토리버스 크리에이터 (Storyverse Creator)**

부제: AI 에이전트 협업 기반 IP 세계관 확장 플랫폼

### 1.2 한 줄 정의
> IP 보유사의 콘텐츠를 다양한 포맷으로 확장하되, 세계관의 일관성을 AI가 자동으로 보장하는 창작 도구

### 1.3 타겟 사용자

| 구분 | 대상 | 니즈 |
|------|------|------|
| Primary | IP 보유사 (갤럭시코퍼레이션 등) | IP 활용 극대화, 품질 관리 |
| Secondary | 콘텐츠 창작자 | 창작 효율화, 원작 연구 시간 단축 |
| Tertiary | 1인 창작자 | 자체 세계관 구축, 일관성 검증 |

## 2. 기획 의도 및 비전

### 2.1 문제 정의

#### 현재 IP 확장의 문제점

```
┌─────────────────────────────────────────────────────────────┐
│  기존 IP 확장 프로세스                                        │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  원작 분석 ──▶ 설정집 작성 ──▶ 창작 ──▶ 검수 ──▶ 수정      │
│     ↑            (수동)       (개별)   (수동)    (반복)     │
│     │                                                       │
│     └──────────── 피드백 루프 (비효율) ────────────────────┘ │
│                                                             │
│  • 원작 연구에 평균 2-4주 소요                               │
│  • 세계관 오류 발생률 30% 이상                               │
│  • 검수-수정 사이클 평균 3회 반복                            │
│  • IP사-창작자 간 커뮤니케이션 비용 높음                     │
└─────────────────────────────────────────────────────────────┘
```

#### 스토리버스의 해결책

```

│                              │                              │

│                    ┌─────────────────┐                      │
│                    │  세계관 일관성   │                      │

│                                                             │
│  • 원작 분석 시간: 2주 → 즉시                               │
│  • 세계관 오류율: 30% → 5% 미만                             │
│  • 검수 사이클: 3회 → 1회                                   │
│  • 제작 시간: 70% 단축                                      │
└─────────────────────────────────────────────────────────────┘
```

### 2.2 비전 선언문

> "모든 IP가 무한한 가능성을 가질 수 있도록,
> AI와 인간이 협업하여 세계관을 확장하는 새로운 창작 패러다임을 만든다."

### 2.3 미션

1. **일관성 있는 확장**: 원작의 본질을 유지하면서 새로운 이야기 창조
2. **창작의 민주화**: 전문 작가가 아니어도 고품질 파생 콘텐츠 제작 가능
3. **IP 가치 극대화**: 하나의 IP에서 다양한 포맷의 콘텐츠 생성
4. **권리 보호**: IP 보유사와 창작자 모두의 권리를 보장하는 시스템

### 3.2 세계관 일관성 보장

```
일관성 검증 항목
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. 시간선 일관성 (Timeline Consistency)
   ├── 사건 발생 순서 검증
   ├── 캐릭터 나이 계산
   └── 역사적 사실과의 정합성

2. 캐릭터 일관성 (Character Consistency)
   ├── MBTI 기반 행동 패턴
   ├── 말투/어휘 스타일
   └── 관계 다이나믹

3. 공간 일관성 (Spatial Consistency)
   ├── 장소 간 거리/이동 시간
   ├── 건축 양식 시대 적합성
   └── 지리적 정확성

4. 시각 일관성 (Visual Consistency)
   ├── 색감 팔레트
   ├── 조명 스타일
   └── 의상/소품 시대 고증

5. 서사 일관성 (Narrative Consistency)
   ├── 테마 유지
   ├── 복선 회수
   └── 캐릭터 아크 연속성
```

## 8. 데이터 모델

### 8.1 핵심 엔티티

```sql
-- IP (지적재산권)
CREATE TABLE ips (
    id UUID PRIMARY KEY,
    title VARCHAR(255) NOT NULL,
    type VARCHAR(50), -- '영화', '드라마', '웹툰' 등
    year INTEGER,
    genres TEXT[], -- 배열
    description TEXT,
    thumbnail_url TEXT,
    owner_id UUID REFERENCES users(id),
    worldview JSONB, -- 세계관 데이터
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 프로젝트
CREATE TABLE projects (
    id UUID PRIMARY KEY,
    ip_id UUID REFERENCES ips(id),
    creator_id UUID REFERENCES users(id),
    title VARCHAR(255) NOT NULL,
    creative_intent TEXT,
    expansion_type VARCHAR(50), -- 'prequel', 'side-story', 'sequel'
    formats TEXT[],
    consistency_level INTEGER,
    worldview_rules JSONB,
    status VARCHAR(50) DEFAULT 'draft',
    created_at TIMESTAMP DEFAULT NOW(),
    updated_at TIMESTAMP DEFAULT NOW()
);

-- 에이전트 로그
CREATE TABLE agent_logs (
    id UUID PRIMARY KEY,
    project_id UUID REFERENCES projects(id),
    agent_type VARCHAR(50),
    action VARCHAR(50),
    message TEXT,
    metadata JSONB,
    created_at TIMESTAMP DEFAULT NOW()
);

-- 일관성 리포트
CREATE TABLE consistency_reports (
    id UUID PRIMARY KEY,
    project_id UUID REFERENCES projects(id),
    overall_score INTEGER,
    breakdown JSONB, -- { timeline, character, narrative, visual, audio }
    issues JSONB[],
    created_at TIMESTAMP DEFAULT NOW()
);

-- 결과물
CREATE TABLE outputs (
    id UUID PRIMARY KEY,
    project_id UUID REFERENCES projects(id),
    format VARCHAR(50),
    file_urls TEXT[],
    metadata JSONB,
    approval_status VARCHAR(50) DEFAULT 'pending',
    created_at TIMESTAMP DEFAULT NOW()
);
```

# 인증

# 결과물
