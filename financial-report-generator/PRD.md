# Product Requirements Document (PRD)
# 기업 재무 분석 보고서 자동 생성 시스템

## 1. Executive Summary

### 1.1 프로젝트 개요
DART 공시 자료, 사업보고서, 뉴스 기사 등 다양한 문서를 업로드하면 AI(Claude)를 활용하여 투자자급 품질의 재무 분석 보고서를 자동으로 생성하는 시스템

### 1.2 목표
- 투자자들이 기업 분석에 소요하는 시간을 80% 단축
- 컨설팅 펌(McKinsey, BCG, 삼정KPMG 등) 수준의 보고서 품질 제공
- 다양한 비정형 데이터(뉴스, 기사)를 포함한 종합적 분석

### 1.3 타겟 사용자
- **주요 타겟**: 개인/기관 투자자
- **세부 페르소나**:
  - 가치투자자: 재무제표 심층 분석 필요
  - 기관투자자: 빠른 의사결정을 위한 요약 정보 필요
  - 애널리스트: 경쟁사 비교 및 산업 분석 필요

## 2. Core Features

### 2.1 문서 업로드 및 파싱 (P0 - Critical)

#### 2.1.1 지원 문서 유형
| 문서 타입 | 포맷 | 우선순위 | 추출 정보 |
|----------|------|---------|----------|
| 사업보고서 | PDF, DOCX | P0 | 재무제표, 사업내용, 리스크 |
| 감사보고서 | PDF | P0 | 재무제표, 감사의견 |
| 분기/반기보고서 | PDF, DOCX | P1 | 재무제표, 주요 사항 |
| 뉴스 기사 | TXT, HTML, PDF | P1 | 이슈, 시장 반응, 전망 |
| 산업 리포트 | PDF, DOCX | P2 | 산업 트렌드, 시장 규모 |
| IR 자료 | PDF, PPT | P2 | 경영진 전망, 사업 계획 |

#### 2.1.2 파싱 요구사항
- **재무제표 자동 인식**: 재무상태표, 손익계산서, 현금흐름표
- **텍스트 구조화**: 섹션별 자동 분류 (사업내용, 리스크, 주요사항 등)
- **표/차트 추출**: 이미지 내 표 데이터 OCR 지원
- **다국어 지원**: 한국어 우선, 영어 지원

### 2.2 재무 분석 엔진 (P0 - Critical)

#### 2.2.1 정량 분석
**수익성 지표**
- ROE (자기자본이익률)
- ROA (총자산이익률)
- 영업이익률, 순이익률
- EBITDA, EBITDA 마진

**안정성 지표**
- 부채비율
- 유동비율, 당좌비율
- 이자보상배율
- 차입금의존도

**성장성 지표**
- 매출 성장률 (YoY, QoQ)
- 영업이익 성장률
- 자산 성장률
- CAGR (연평균 성장률)

**활동성 지표**
- 자산회전율
- 재고자산회전율
- 매출채권회전율

**밸류에이션 지표**
- PER (주가수익비율)
- PBR (주가순자산비율)
- PSR (주가매출액비율)
- EV/EBITDA

#### 2.2.2 시계열 분석
- 최소 3년, 최대 10년 트렌드 분석
- 계절성/주기성 패턴 감지
- 이상치(Anomaly) 탐지 및 원인 분석

#### 2.2.3 비교 분석
- **동종업계 비교 (Peer Analysis)**
  - 산업 평균 대비 포지셔닝
  - 경쟁사 top 3-5개 벤치마킹
- **역사적 비교 (Historical Analysis)**
  - 자사 과거 대비 개선/악화 추이

### 2.3 AI 기반 정성 분석 (P0 - Critical)

#### 2.3.1 Claude LLM 활용 분석
- **사업 모델 분석**
  - 수익 구조 파악
  - 경쟁 우위 요소 (Moat) 식별
  - 비즈니스 리스크 요인

- **산업 분석**
  - 산업 성장성 및 전망
  - Porter's 5 Forces 분석
  - 규제 환경 및 정책 리스크

- **뉴스/기사 감성 분석**
  - 긍정/부정/중립 스코어링
  - 주요 이슈 요약
  - 시장 센티먼트 추출

- **ESG 분석**
  - 환경(E), 사회(S), 지배구조(G) 평가
  - ESG 리스크 및 기회 요인

#### 2.3.2 종합 인사이트 생성
- **투자 포인트 (Investment Thesis)**
  - 투자 매력도 3-5가지 핵심 포인트
  - 리스크 요인 3-5가지

- **시나리오 분석**
  - Bull Case (낙관 시나리오)
  - Base Case (기본 시나리오)
  - Bear Case (비관 시나리오)

### 2.4 보고서 생성 (P0 - Critical)

#### 2.4.1 보고서 구조
```
1. Executive Summary (1-2 페이지)
   - 투자 의견 (Buy/Hold/Sell)
   - 핵심 재무 지표 대시보드
   - 3-5줄 요약

2. Company Overview (2-3 페이지)
   - 기업 개요
   - 사업 모델
   - 시장 포지션

3. Financial Analysis (5-7 페이지)
   - 재무제표 요약
   - 주요 재무 비율
   - 시계열 트렌드 차트
   - Peer 비교

4. Qualitative Analysis (3-5 페이지)
   - 산업 분석
   - 경쟁 우위 분석
   - SWOT 분석
   - ESG 평가

5. News & Sentiment Analysis (2-3 페이지)
   - 최근 주요 뉴스 요약
   - 시장 센티먼트
   - 이슈 타임라인

6. Investment View (2-3 페이지)
   - 투자 의견 및 근거
   - 시나리오별 분석
   - 리스크 요인
   - Valuation 분석

7. Appendix
   - 상세 재무제표
   - 방법론 설명
   - 데이터 출처
```

#### 2.4.2 출력 포맷
- **PDF**: 메인 포맷 (프린트/공유 용이)
- **PowerPoint**: 프레젠테이션용 (선택적)
- **Word**: 편집 가능 버전 (선택적)

#### 2.4.3 시각화 요구사항
- **차트 타입**
  - 시계열 라인 차트 (트렌드)
  - 바 차트 (비교 분석)
  - 레이더 차트 (재무 비율 비교)
  - 워터폴 차트 (손익 분해)
  - 히트맵 (상관관계)

- **디자인 가이드라인**
  - 투자은행(IB) 스타일 템플릿
  - 컬러: 프로페셔널 파레트 (파랑, 회색 기조)
  - 폰트: 가독성 높은 sans-serif

### 2.5 사용자 인터페이스 (P0 - Critical)

#### 2.5.1 웹 기반 UI (Streamlit)
- **업로드 페이지**
  - Drag & Drop 파일 업로드
  - 다중 파일 지원
  - 진행 상황 표시

- **설정 페이지**
  - 분석 옵션 선택
    - 분석 깊이 (간략/표준/심층)
    - 비교 기업 선택
    - 포함할 섹션 선택
  - 보고서 커스터마이징
    - 회사 로고 업로드
    - 템플릿 선택

- **결과 페이지**
  - 실시간 생성 과정 표시
  - 보고서 미리보기
  - 다운로드 버튼

## 3. Technical Requirements

### 3.1 성능 요구사항
- **처리 시간**:
  - 문서 파싱: 파일당 < 30초
  - 재무 분석: < 1분
  - AI 분석: < 3분
  - 보고서 생성: < 2분
  - **총 소요시간: < 7분** (일반적인 케이스)

- **동시 사용자**: 초기 50명, 확장 가능한 아키텍처

- **파일 크기**: 최대 100MB per file

### 3.2 데이터 요구사항
- **데이터 저장**
  - 업로드된 파일: 30일 보관
  - 생성된 보고서: 90일 보관
  - 파싱된 재무 데이터: 영구 보관 (분석용)

- **데이터 보안**
  - 파일 암호화 (at rest, in transit)
  - 사용자별 데이터 격리
  - GDPR/개인정보보호법 준수

### 3.3 API 요구사항
- **Claude API**
  - Model: claude-3-5-sonnet (최신)
  - Rate limit 관리
  - Cost 최적화 (Caching 활용)

- **외부 데이터 API (선택적)**
  - 금융 데이터: Yahoo Finance, Alpha Vantage
  - 환율 데이터: 한국은행 API
  - 산업 데이터: 통계청 API

## 4. User Stories

### 4.1 핵심 사용자 스토리

**US-001: 기본 보고서 생성**
```
As a 개인 투자자
I want to 삼성전자의 사업보고서를 업로드하여 투자 분석 보고서를 생성하고 싶다
So that 전문가 수준의 분석을 빠르게 얻을 수 있다

Acceptance Criteria:
- PDF 사업보고서 업로드 가능
- 7분 이내 분석 완료
- PDF 보고서 다운로드 가능
- 주요 재무 지표 포함
```

**US-002: 다중 문서 종합 분석**
```
As a 기관 투자자
I want to 사업보고서 + 최근 3개월 뉴스 기사를 함께 업로드하고 싶다
So that 재무 데이터와 시장 센티먼트를 종합적으로 분석할 수 있다

Acceptance Criteria:
- 10개 이상 파일 동시 업로드 가능
- 문서 타입 자동 분류
- 정량/정성 분석 통합
- 뉴스 기반 리스크 요인 식별
```

**US-003: 경쟁사 비교 분석**
```
As a 애널리스트
I want to LG전자, 삼성전자, 애플의 보고서를 업로드하여 비교하고 싶다
So that 산업 내 상대적 경쟁력을 평가할 수 있다

Acceptance Criteria:
- 3개 이상 기업 동시 분석 가능
- Side-by-side 재무 지표 비교 차트
- 상대적 강점/약점 도출
```

## 5. Success Metrics

### 5.1 Product Metrics
- **사용자 만족도**
  - 보고서 품질 평가: > 4.0/5.0
  - 사용 편의성: > 4.5/5.0

- **사용 지표**
  - DAU (Daily Active Users): 100명 (6개월 목표)
  - 보고서 생성 수: 1,000건/월
  - 재사용률: > 60%

- **비즈니스 지표**
  - 투자 의사결정 시간 단축: > 70%
  - 분석 비용 절감: > 80%

### 5.2 Technical Metrics
- **성능**
  - Uptime: > 99.5%
  - API 응답 시간: < 200ms (p95)
  - 보고서 생성 성공률: > 95%

- **품질**
  - 재무 데이터 추출 정확도: > 98%
  - AI 인사이트 관련성: > 90% (사용자 피드백 기반)

## 6. Project Phases

### Phase 1: MVP (Minimum Viable Product) - 4주
**목표**: 핵심 기능 검증
- 사업보고서(PDF) 파싱
- 기본 재무 분석 (10개 핵심 지표)
- Claude 기반 Executive Summary 생성
- 간단한 PDF 보고서 출력
- Streamlit 기본 UI

**Success Criteria**: 1개 사업보고서 → 5페이지 보고서 생성

### Phase 2: 기능 확장 - 6주
- 다중 문서 타입 지원 (뉴스, 기사)
- 고급 재무 분석 (30+ 지표)
- Peer 비교 분석
- 고급 시각화 (10+ 차트 타입)
- 보고서 템플릿 다양화

### Phase 3: AI 고도화 - 4주
- 산업 분석 자동화
- SWOT 자동 생성
- 시나리오 분석
- ESG 평가
- 투자 의견 생성

### Phase 4: 최적화 & Scale - 4주
- 성능 최적화
- 사용자 피드백 반영
- 추가 출력 포맷 (PPT, Word)
- API 제공 (선택적)

## 8. Dependencies & Risks

### 8.1 주요 의존성
- **Claude API**: 서비스 가용성, 비용
- **문서 파싱 라이브러리**: PDF 구조 복잡도
- **재무 데이터 품질**: 입력 문서의 표준화 정도

### 8.2 리스크 및 완화 전략

| 리스크 | 영향도 | 완화 전략 |
|--------|--------|----------|
| PDF 파싱 실패 (비정형 문서) | High | 다중 파싱 엔진 사용, OCR fallback |
| Claude API 비용 초과 | Medium | Caching, Prompt 최적화, 단계별 호출 |
| 재무 데이터 추출 오류 | High | Rule-based + AI hybrid, 사용자 검증 단계 |
| 보고서 생성 시간 초과 | Medium | 비동기 처리, 진행 상황 표시 |
